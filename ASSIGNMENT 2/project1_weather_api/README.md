# Mini-Project 1 — Weather Forecast API

Install `pip install -r requirements.txt`, then open `project1_weather_forecast.ipynb` and use Restart & Run All. Run offline tests with `python -m pytest -q`.

Includes urllib and requests geocoding, forecast retrieval, status/content-type/latency diagnostics, WMO weather-code decoding, plots, retry logic, sample JSON and tests. Live calls need internet access. Replace the email placeholder with your real university email before calling MET Norway.

API references: Open-Meteo https://open-meteo.com/en/docs, geocoding https://open-meteo.com/en/docs/geocoding-api, terms https://open-meteo.com/en/terms; MET Norway https://api.met.no/doc/TermsOfService and https://api.met.no/doc/GettingStarted. Check current terms and attribution before production use.

The report discusses data flow, terms, reliability and privacy. AI assistance was used to draft code and documentation; review and understand the implementation before submission.
